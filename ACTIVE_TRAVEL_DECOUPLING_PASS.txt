Sterling Spend — Active Travel Decoupling Pass

Confirmed behavior implemented:
- Activating an Event calculates/stores planned travel independently of reimbursement status.
- A submitted/reviewed/paid reimbursement can no longer block active Event mileage/toll calculation.
- Closed reimbursements are never reopened or mutated by automatic travel.
- For a fresh month with no reimbursement record, current behavior still creates an open working reimbursement and links the automatic mileage line.
- If only a closed reimbursement exists, travel remains saved on the active Event session and still appears on the employee home as Mileage.
- Automatic travel can optionally link to an open reimbursement, but that link is secondary and not required for the travel calculation to succeed.
- The old one-mileage-entry-per-event/day index is removed; automatic mileage can instead link to the specific Event activation/session.

No generic Trip schema, expected-total model, or submission-grain redesign is introduced here.
